Example 6.15

Find the value of each of the following:

(a)
log9⁡729
(b)
log⁡0.0000013
(c)
log⁡1000005
(d)
log3⁡1273

Solution

(a)
log9⁡729=log9⁡(729)12
=12log9⁡93
=12×3log9⁡9
=32

Therefore, log9⁡729=32

(b)
log⁡0.0000013=log⁡(0.000001)13
=log⁡(10−6)13
=log⁡10−63
=log⁡10−2
=−2log⁡10
=−2×1

Therefore, log⁡0.0000013=−2

(c)
log⁡1000005=log⁡(100000)15
=15log⁡100000
=15log⁡105
=15×5log⁡10
=15×5×1
=1

Therefore, log⁡1000005=1

(d)
log3⁡127=log3⁡(127)12
=12log3⁡(127)
=12log3⁡(13)3
=12×3log3⁡(13)
=32log3⁡3−1
=32×(−1)log3⁡3
=−32×1
=−32

Therefore, log3⁡127=−32

Example 6.16

Determine the value of x given that log2⁡x=log2⁡2−log2⁡3

Logarithms

Solution

Given log2⁡x=log2⁡2−log2⁡3. It implies that,

log2⁡x=log2⁡(23)

Thus, x=23.

Therefore, x=23.
