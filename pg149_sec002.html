Subsets

Set A is a subset of another set B if all elements of A are also elements of B.

For example, if A = {a, b, c, e} and B = {a, b, c, d, e}, then A is a subset of B because all elements of A belong to B.

If A has less elements than B, then A is called a proper subset of B, denoted by A ⊂ B.

If A is a subset of B and the two sets are equal, then A is called an improper subset of B, written as A ⊆ B.

If A = B, then A ⊆ B and B ⊆ A.

Therefore, a subset of a set can either be proper or improper.
