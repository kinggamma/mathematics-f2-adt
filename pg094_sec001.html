Example 5.2

Write each of the following expressions in power form:

  1. (a) 6×6×6×6×6×6×6×6
  2. (b) (−34)×(−34)×(−34)×(−34)
  3. (c) 10×10×10×10×10×10
  4. (d) (−7)×(−7)×(−7)

Solution

  1. 6×6×6×6×6×6×6×6=68
  2. (−34)×(−34)×(−34)×(−34)=(−34)4
  3. 10×10×10×10×10×10=106
  4. (−7)×(−7)×(−7)=(−7)3

Example 5.3

Identify the power, base and exponent in each of the following exponential numbers:

  1. 43
  2. (−10)6
  3. xn

Solution

  1. (a) 43 is the power, 4 is the base and 3 is the exponent.
  2. (b) (−10)6 is the power, −10 is the base and 6 is an exponent.
  3. (c) xn is the power, x is the base and n is an exponent.

Example 5.4

Evaluate each of the following powers:

  1. 54
  2. (−5)3
  3. (−7)2
  4. 26

Solution

  1. 54=5×5×5×5=625
  2. (−5)3=(−5)×(−5)×(−5)=−125
  3. (−7)2=(−7)×(−7)=49
  4. 26=2×2×2×2×2×2=64

Example 5.5

Express each of the following numbers in exponential form using the indicated base.

  1. (a) 64 in base 4
  2. (b) 2401 in base 7
  3. (c) −125 in base −5

Solution

  1. 64=4×4×4=43
  2. 2401=7×7×7×7=74
  3. −125=(−5)×(−5)×(−5)=(−5)3
