Example 7.8

Find A∪B if A = {a, b, c, d, e, f} and B = {a, e, i, o, u}.

Solution

Given A = {a, b, c, d, e, f} and B = {a, e, i, o, u}. It follows that, A∪B = {a, b, c, d, e, f, i, o, u}. Therefore, A∪B = {a, b, c, d, e, f, i, o, u}.

Intersection of sets

The intersection of sets, A and B is the set which contains all the elements that are common to both sets. It is denoted by the cap symbol “∩”. Thus, the intersection of sets A and B is written as A∩B, which means, x∈A∩B if x∈A and x∈B. The keyword for intersection is “and”. For example, if A = {1, 2, 3, 4, 5} and B = {1, 3, 5}, then A∩B = {1, 3, 5}.

Example 7.10

Find A∩B if A = {a, e, i} and B = {b, c, f}. State if A and B are disjoint sets or not.

Solution

Given A = {a, e, i} and B = {b, c, f}. The sets A and B do not have common elements. Thus, A and B are disjoint sets. Therefore, A∩B = ∅.
