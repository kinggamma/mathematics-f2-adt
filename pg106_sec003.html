Fractional exponents

Numbers in power form can be written in exponential form with fractional exponents. For example, 512 is a power with 12 as an exponent.

Taking the square of 512 gives

\left(5^{\frac{1}{2}}\right)2 = 512×2\;(by power law)
= 5

Note that the only number which when squared gives 5 is 5, this implies that 512=5.

Similar approach can be applied to other powers. For instance:

(513)3=513×3
= 5

Based on the previous results, it can be concluded that if x is a real number and n is any real number, then

\left(x^{\frac{1}{n}}\right)n = x1n⋅n = x  and  x1n = \sqrt[n]{x}.

Generally, x1n=xn, for x>0.

Example 5.22

Find the value of 4912.

Solution

Express 49 as a product of prime factors.

49=7×7=72
Thus,  4912 = \left(7^2\right)12 = 72×12 = 71
Therefore,  4912 = 7.

Example 5.23

Simplify (827)13.

Solution

Express the base in power form and simplify.

(827)13=(23×23×23)13
=((23)3)13=23
Therefore,  \left(\frac{8}{27}\right)13 = 23.

Example 5.24

Find the value of (−125)13.

Solution

Express –125 as a product of prime factors.

−125=(−5)×(−5)×(−5)
(−125)13=((−5)3)13
=(−5)3×13
= -5
Therefore,  (-125)13 = -5.
