Example 6.17

Given that log⁡2=0.30103 and log⁡3=0.47712. Calculate the value of log⁡48.

Solution

log⁡48=log⁡(24×3)
=log⁡24+log⁡3
=4log⁡2+log⁡3
= 4(0.30103) + 0.47712
= 1.68124

Therefore, log⁡48=1.68124.

Example 6.18

Find the value of x given that

loga⁡x=12loga⁡4+13loga⁡27.

Solution

loga⁡x=12loga⁡4+13loga⁡27
=loga⁡412+loga⁡2713
=loga⁡2+loga⁡3
=loga⁡(2×3)
=loga⁡6

Thus, loga⁡x=loga⁡6.

Therefore, x=6.

Example 6.19

Simplify log⁡6log⁡216.

Solution

log⁡6log⁡216=log⁡6log⁡63
=log⁡63log⁡6
