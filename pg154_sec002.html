Number of elements in a set

The number of elements in a finite set is found by counting each element in the set.

The number of elements in a set is also known as the cardinality of the set.

For example, you might want to find the number of elements in the union, intersection, or complements of finite sets.

If the set is infinity, then its cardinality is infinities.
