Example 5.9

Write each of the following expressions by grouping together the letters with the same exponents:

(a)
d4t4
(b)
a5×b4
(c)
3cd2×5c5d4

Solution

(a)
d4t4=(dt)4
(b)
a5×b4=a×a4×b4
=a×(ab)4
= a(ab)^4
(c)
3cd2×5c5d4=3×5×c×c5×d2×d4
=15×c6d6
= 15(cd)^6
