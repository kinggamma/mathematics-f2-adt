Sets can be described in different ways. The most common ways of describing a set are: by statement form, by listing (roster form), and by a formula (set builder notation). For instance, if set A is a set of even numbers, then it can be described as follows:

(a) Statement form: A = {even numbers} (b) By listing: A = {2, 4, 6, 8, 10, } (c) Using a formula:

A = {x:x=2n, where n∈ℕ}

and is read as A is the set of all x such that x is an even number.

Example 7.1

Given a set A = {odd numbers between 1 and 10}. Describe the set A by; (a) listing (b) set builder notation

Solution

(a) A = {3, 5, 7, 9}

(b)\ A = {x:x=2n−1, where n∈ℕ and 2≤n≤5}.

Example 7.2

Describe the following sets in roster form. (a) The set of all letters in the word “AGRICULTURE”. (b) The set of all letters in the word “DISTINGUISH”. (c) The set of all vowels in the word “EQUATION”.

Solution

(a) It is observed that the distinct letters in the word “AGRICULTURE” are A, C, E, G, I, L, R, T, and U. Since the order in which the elements are written does not matter and the repetition of elements has no effect, then the set of all letters in the word AGRICULTURE is: {A, C, E, G, I, L, R, T, U}

(b) The word “DISTINGUISH” has the following distinct letters: D, I, S, T, N, G, U, and H. Therefore, the set of all letters in DISTINGUISH is: {D, I, S, T, N, G, U, H}.

(c) The word “EQUATION” has the vowels: A, E, I, O, and U. Therefore, the set of all vowels in the world EQUATION is: {A, E, I, O, U}.
