Example 8.8

Find the exact value of 2sin⁡60∘+cos⁡30∘.

Solution

Using the values in Table 8.1, it follows that;

sin⁡ 60∘ = 32  and  cos⁡ 30∘ = 32.

Thus,

2sin⁡60∘+cos⁡30∘=2×32+32
=332.

Therefore, 2cos⁡60∘+cos⁡30∘=332.

Example 8.9

An isosceles triangle PQR is such that PQ^R=45∘ and RP^Q=90∘. If PQ=6cm, find the length of RQ, giving the answer in radical form.

Solution

Consider the triangle PQR.

From the △PQR, it follows that,

cos⁡45∘=PQRQ=6RQ
RQ=6cos⁡45∘
=622
=62

Therefore, RQ=62 cm.

Example 8.10

Find the values of a, b, and c in the triangle LMP.

Solution

In △LMN, apply the Pythagoras' theorem. That is,

LN2=LM2+MN2
a2=102+102
a2=200
a=102 cm

In △LMP, it implies that,

tan⁡30∘=LMMP

Thus,

33=10MP
MP=10×33
=103 cm

But, MP=10+b.

103=10+b

Thus, b=10(3−1) cm.

In △LMP, it follows that,

sin⁡30∘=LMLP

Thus, 12=10cmc.

c=2×10=20cm

Therefore,

a=102cm, b=10(3−1)cm, and c=20cm.
